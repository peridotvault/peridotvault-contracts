# Audit Methodology

The PeridotVault audit documentation tracks security review scope, assumptions, findings, and remediation status.

Methodology:

- Review account initialization and authority transitions
- Verify PDA seed correctness and bump handling
- Review CPI authorization boundaries
- Check payment-token and fee accounting paths
- Review economic assumptions and incentive risks
- Compare tests against critical user flows
- Record findings with severity, impact, likelihood, and remediation status

Audit docs are Markdown-first so reports can be updated as the contracts evolve.
