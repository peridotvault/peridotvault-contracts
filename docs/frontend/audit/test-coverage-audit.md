# Test Coverage Audit

Test coverage should map directly to critical contract behavior.

Expected coverage groups:

- Initialization flows
- Authority changes
- Payment-token management
- Publisher game creation
- Registry game status updates
- Store game configuration
- Purchase success paths
- Purchase rejection paths
- Discount and referral edge cases
- CPI failure cases
- Account close flows

Coverage gaps should be tracked in the remediation plan with owner, priority, and target test file.
