# Economic Security Audit

Economic review focuses on value movement, fee policy, and abuse resistance.

Review areas:

- Publish fees
- Platform fees
- Referral caps
- Discounts
- Payment-token activation and removal
- Treasury routing
- Duplicate purchase handling

Audit questions:

- Can fee settings exceed intended bounds?
- Can discounts underflow or bypass payment?
- Can referral rewards exceed configured caps?
- Can inactive payment tokens still be used?
- Can treasury updates redirect funds unexpectedly?
