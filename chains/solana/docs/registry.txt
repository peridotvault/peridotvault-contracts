Registry (PeridotVault Registry v1)

Program Identity
- Program ID: DCYPxPtnVeBgy56SYMT6GPBMJp8NJNLmE46QfHYqCgGL
- Anchor module: registry
- Crate/lib: registry

Overview
- Registry adalah onboarding + governance layer untuk game canonical.
- Fungsi utama:
  - konfigurasi admin registry
  - allowlist payment token onboarding + fee per token
  - publish grant (fee exemption) — create dan update terpisah
  - CPI create game ke PGL-1 + register game
  - CPI ke Game Store untuk init config + set price (paid/free)
  - kontrol status game (Active/Suspended/Banned)
  - close registry game (reclaim rent, hanya Suspended/Banned)

Program Scope
- In scope:
  - onboarding game ke ekosistem melalui register flow
  - governance status game (Active/Suspended/Banned)
  - fee onboarding berdasarkan payment token allowlist
  - grant fee exemption untuk publisher tertentu
- Out of scope:
  - mutasi metadata/publisher game canonical (tetap di PGL-1)
  - listing price, discount, dan purchase settlement (tetap di Game Store)

Authority Model
- Registry Admin (`registry_config.authority`)
  - full kontrol config registry, payment token, publish grant, dan status game
- Publisher (signer saat `create_game_and_register`)
  - membuat game baru via CPI ke PGL-1 dan mendaftarkan game tersebut
- Trust anchor ke PGL-1:
  - `registry_config.pgl1_program` menjadi root of trust untuk CPI create game

Program-Level Access Control
- Global admin gate:
  - seluruh instruction governance/config memakai `has_one authority`
- Publisher gate:
  - `create_game_and_register` wajib signer publisher valid dan account payment token sesuai owner signer
  - `create_publish_grant` dan `update_publish_grant` wajib publisher signer
- CPI trust gate:
  - `pgl1_program` harus match allowlist di config
  - `pgl_config` wajib PDA canonical dari program PGL-1 tersebut
  - `pgl_treasury` wajib sama dengan `pgl_config.treasury`
- State transition gate:
  - status transition dibatasi finite-state rule, khususnya `Banned` final/non-reversible

Authorized Actor / Entity Model
- Registry tidak memakai model `authorized_actor` seperti PGL-1.
- Entitas yang dianggap "authorized" di registry berbasis:
  - role admin (authority signer)
  - allowlist `AcceptedPaymentToken` (token yang boleh dipakai fee)
  - publish grant PDA untuk publisher tertentu (fee exemption policy)

Publisher Authority Model
- Registry tidak menyimpan pubkey publisher sebagai authority state untuk game.
- Otoritas publisher selalu direferensikan lewat signer saat call + data canonical di PGL-1 game account.

State Accounts
1. RegistryConfig
- authority: Pubkey
- treasury: Pubkey
- pgl1_program: Pubkey (program PGL-1 yang diizinkan)
- bump: u8

2. AcceptedPaymentToken
- mint: Pubkey
- active: bool
- fee_amount: u64
- bump: u8

3. RegistryGame
- game: Pubkey
- game_id: String (max 64)
- registered_at: i64
- status: GameStatus
- bump: u8
- PDA seed: ["registry_game", game_pubkey] — uniqueness enforced via PDA collision.

4. PublishGrant
- expired_at: Option<i64>
- bump: u8
- None = grant aktif tanpa batas waktu.

Enum
- GameStatus::Active (0)
- GameStatus::Suspended (1)
- GameStatus::Banned (2)

PDA Seeds
- registry_config: ["registry_config"]
- accepted_payment_token: ["accepted_payment_token", mint_pubkey]
- registry_game: ["registry_game", game_pubkey]
- publish_grant: ["publish_grant", publisher_pubkey]

Instruction Security Matrix
- initialize_registry
  - Caller: signer pertama (authority awal)
  - Guard: init config sekali, treasury != default
- set_treasury
  - Caller: Admin Registry
  - Guard: has_one authority, treasury != default
- add_payment_token
  - Caller: Admin Registry
  - Guard: has_one authority, fee_amount > 0
- update_payment_token
  - Caller: Admin Registry
  - Guard: has_one authority, fee_amount > 0
- remove_payment_token
  - Caller: Admin Registry
  - Guard: has_one authority
- create_publish_grant
  - Caller: Admin Registry
  - Guard: has_one authority, publisher signer, expired_at > now (jika ada)
- update_publish_grant
  - Caller: Admin Registry
  - Guard: has_one authority, publisher signer, expired_at > now (jika ada)
- create_game_and_register
  - Caller: Publisher signer
  - Guard:
    - game_id/metadata_uri valid (game_id max 64, metadata_uri max 256)
    - self_program == registry program ID
    - store_program == Game Store program ID (allowlist)
    - pgl1_program harus == config.pgl1_program
    - pgl_config harus PDA canonical PGL-1
    - pgl_treasury harus == pgl_config.treasury
    - fee onboarding ditagih jika grant tidak aktif (token dipilih via payment_mint account)
    - registry_game uniqueness (PDA collision via game_pubkey)
    - Jika base_price + mint_token Some: remaining accounts untuk store payment option wajib tersedia
- update_game_status
  - Caller: Admin Registry
  - Guard: has_one authority + finite transition rule
- close_registry_game
  - Caller: Publisher signer
  - Guard: game status harus Suspended atau Banned, treasury account match config.treasury
  - Effect: registry_game PDA di-close, rent SOL dikirim ke treasury (bukan publisher)

Flow Per Instruction
1. initialize_registry(treasury)
- Validasi treasury.
- Init registry_config.
- Simpan authority, treasury, dan pgl1_program default = ID PGL-1.

2. set_treasury(treasury)
- Validasi admin.
- Validasi treasury non-default.
- Update treasury.

3. add_payment_token(fee_amount)
- Validasi admin.
- Validasi fee_amount > 0.
- Buat accepted_payment_token + set active=true.

4. update_payment_token(active, fee_amount)
- Validasi admin.
- Validasi fee_amount > 0.
- Update status dan fee.

5. remove_payment_token()
- Validasi admin.
- Close accepted_payment_token.

6a. create_publish_grant(publisher, expired_at)
- Validasi admin + publisher signer.
- Validasi expired_at > now (jika ada).
- Init publish_grant PDA.

6b. update_publish_grant(publisher, expired_at)
- Validasi admin + publisher signer.
- Validasi expired_at > now (jika ada).
- Update expired_at pada grant yang sudah ada.

7. create_game_and_register(game_id, metadata_uri, base_price, mint_token)
- Validasi input game (game_id max 64, metadata_uri max 256).
- Validasi self_program == registry program ID.
- Validasi store_program == Game Store program ID.
- Validasi trust boundary PGL-1 (program/config/treasury).
- Cek publish grant optional dari remaining account (index 0).
- Jika grant tidak aktif: transfer_checked fee publisher -> treasury menggunakan payment_mint.
- CPI call `pgl1::create_game`.
- Init registry_game (seed: game_pubkey) dengan status default Active.
- CPI ke Game Store `init_game_store_config` (active=true, default referral & discount).
- Jika base_price Some(price) DAN mint_token Some(mint):
  - remaining_accounts[1] = store_accepted_payment_token (store's allowlist)
  - remaining_accounts[2] = store_game_payment_option (PDA di-init)
  - CPI ke Game Store `set_game_payment_option` dengan base_price, active=true, dan mint_token.
  - Game-store akan validasi: mint_token ada di store's AcceptedPaymentToken.
- Jika base_price None ATAU mint_token None: game gratis, tidak ada GamePaymentOption yang dibuat.

8. update_game_status(status_u8)
- Validasi admin.
- Parse status target.
- Validasi transisi:
  - Active <-> Suspended
  - Active -> Banned
  - Suspended -> Banned
  - Banned -> (tidak bisa balik)
- Update status.

9. close_registry_game()
- Validasi publisher signer.
- Validasi game status == Suspended atau Banned (GameNotClosable jika Active).
- Validasi treasury account match config.treasury.
- Close registry_game PDA — rent SOL dikirim ke treasury (revenue untuk registry).
- Game data hilang dari registry (tidak bisa di-recover).
- Publisher bisa call instruction ini untuk cleanup game yang sudah di-suspend/ban.
- Konsekuensi: publisher tidak dapat refund rent SOL, treasury mendapat SOL dari close.

Default Status
- Game baru hasil `create_game_and_register` langsung berstatus `Active`.

Grant Semantics
- Publish grant aktif jika:
  - account publish_grant valid untuk publisher
  - `expired_at` == None, atau `now <= expired_at`
- Saat grant aktif, fee token onboarding di-skip.

Required Accounts Even When Grant Active
- Walaupun grant aktif, account list berikut tetap wajib tersedia:
  - payment_mint
  - accepted_payment_token
  - publisher_payment_account
  - treasury_payment_account
  - token_program
- Fee bisa nol (skipped), tapi account masih dibutuhkan untuk struktur accounts instruction.

Remaining Accounts Layout for create_game_and_register
- Index 0: publish_grant (optional) — untuk fee exemption
- Index 1: store_accepted_payment_token (hanya jika base_price + mint_token Some)
- Index 2: store_game_payment_option (hanya jika base_price + mint_token Some)
- Jika grant ada DAN game berbayar: [grant, store_token, store_option]
- Jika grant ada DAN game gratis: [grant]
- Jika grant tidak ada DAN game berbayar: [store_token, store_option]
- Jika grant tidak ada DAN game gratis: []

CPI Trust Assumptions
- Registry sekarang mengunci target PGL-1 via `config.pgl1_program`.
- `pgl_config` harus PDA canonical dari program PGL-1 tersebut.
- `pgl_treasury` harus cocok dengan `pgl_config.treasury`.
- Dengan ini, misrouting CPI ke program/config palsu terblokir.
- CPI ke Game Store dikunci via `store_program` (harus match Game Store program ID).
- `store_authorized_source_program` dan `store_authorized_registry_program` divalidasi via seeds.
- Game-store CPI menggunakan manual instruction construction (hardcoded discriminators) karena circular dependency registry <-> game-store. Discriminators harus diupdate jika game-store program berubah.

Economic Model
- Registry mendapat revenue dari:
  - Onboarding fee per game (berdasarkan AcceptedPaymentToken.fee_amount)
  - Rent SOL dari close_registry_game (rent dari PDA registry_game yang di-close)
- Publisher membayar:
  - Onboarding fee saat create_game_and_register (kecuali punya active publish grant)
  - Rent SOL untuk registry_game PDA (tidak bisa di-recover, kecuali game di-close → rent ke treasury)
- close_registry_game adalah konsekuensi bagi publisher: game dihapus, rent SOL masuk treasury registry.
