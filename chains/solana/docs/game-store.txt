Overview
- Game Store adalah commerce layer untuk game canonical dari PGL-1 + Registry.
- Tanggung jawab utama:
  - config global store (treasury, fee, referral, store_actor)
  - allowlist source program, registry program, payment token
  - listing config per game + payment option
  - discount/referral override per game
  - buy flow settlement + license issue + receipt

Publisher Authority Model
- Game Store tidak menyimpan publisher pubkey di account state store.
- Semua mutasi oleh publisher selalu divalidasi langsung terhadap `pgl1::Game.publisher`.

Instruction Security Matrix
- initialize_store
  - Caller: signer pertama (authority awal)
  - Guard: treasury != default, store_actor != default, BPS boundary valid
- set_treasury / set_platform_fee / set_default_referral / set_max_referral
  - Caller: Admin Store
  - Guard: has_one authority + boundary checks
- add/update authorized_source_program
  - Caller: Admin Store
  - Guard: has_one authority
- add/update authorized_registry_program
  - Caller: Admin Store
  - Guard: has_one authority
- add/update payment_token
  - Caller: Admin Store
  - Guard: has_one authority
- init_game_store_config
  - Caller: Publisher
  - Guard: source+registry authorized active, registry_game<->game match, registry status Active, game.publisher == signer
- set_game_store_active
  - Caller: Publisher
  - Guard: validasi sama seperti init_game_store_config
- set_game_payment_option
  - Caller: Publisher
  - Guard: publisher owner, registry Active, store config active, accepted token active, base_price > 0
- remove_game_payment_option
  - Caller: Publisher
  - Guard: publisher owner + mint match
- set_discount / clear_discount
  - Caller: Publisher
  - Guard: publisher owner, registry Active (set_discount), window/bps valid
- set_referral_bps
  - Caller: Publisher
  - Guard: publisher owner, value <= max_referral_bps
- buy_game
  - Caller: Buyer
  - Guard:
    - registry status Active
    - listing aktif
    - paid_amount == final_price
    - payment mint & token accounts konsisten
    - store_actor signer harus cocok config dan authorized di PGL-1
    - mint license via CPI + receipt write

Flow Per Instruction
1. initialize_store(...)
- Validasi treasury/store_actor non-default.
- Validasi BPS invariants.
- Init store_config.

2. set_treasury / set_platform_fee / set_default_referral / set_max_referral
- Validasi admin.
- Validasi boundary.
- Update config.

3. add/update authorized_source_program / authorized_registry_program
- Validasi admin.
- Init/update status active.

4. add/update payment_token
- Validasi admin.
- Init/update token status active.

5. init_game_store_config(active)
- Validasi source+registry authorized.
- Validasi publisher ownership + registry status Active.
- Init game_store_config.

6. set_game_store_active(active)
- Validasi publisher ownership + linkage game/registry.
- Update active flag.

7. set_game_payment_option(base_price, active)
- Validasi publisher ownership.
- Validasi registry active + game_store_config active.
- Validasi accepted payment token active.
- init_if_needed dan update game_payment_option.

8. remove_game_payment_option()
- Validasi publisher ownership + mint match.
- Close game_payment_option.

9. set_discount(discount_bps, starts_at, expires_at)
- Validasi publisher ownership + registry active.
- Validasi bps dan rentang waktu discount.
- Update field discount.

10. clear_discount()
- Validasi publisher ownership.
- Reset seluruh field discount ke None.

11. set_referral_bps(referral_bps)
- Validasi publisher ownership.
- Normalisasi value:
  - None -> None
  - Some(0) -> None
  - Some(v>0) -> Some(v), v <= max_referral_bps

12. buy_game(paid_amount, referrer)
- Validasi registry status, listing status, payment mint, dan final price.
- Hitung split nominal:
  - platform_fee_amount
  - publisher_amount
  - referral_amount (jika referrer ada)
- Transfer SPL token buyer -> treasury.
- Transfer SPL token buyer -> publisher.
- Jika referral_amount > 0, transfer buyer -> referrer (dengan validasi token account referrer).
- CPI `pgl1::mint_license` menggunakan `store_actor` yang authorized.
- Simpan purchase_receipt dan emit event.

Buy Flow (Current vs Target)
- Current:
  - Settlement SPL token + mint license + receipt sudah aktif.
- Target lanjutan (belum ada):
  - refund/cancel flow
  - dispute/reconciliation flow
  - anti-fraud policy layer tambahan

Operational Prerequisites
1. `initialize_store` sudah dijalankan.
2. `authorized_source_program` dan `authorized_registry_program` sudah aktif.
3. `accepted_payment_token` store sudah aktif.
4. Game sudah terdaftar di Registry dengan status `Active`.
5. `init_game_store_config` + `set_game_payment_option` sudah dilakukan publisher.
6. `store_actor` ada di PGL-1 authorized_actor dan status active.
